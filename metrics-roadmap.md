# Performance metrics roadmap

The implemented analytics phases and the authoritative deferral log live in
[`ADR-0033`](ADR/ADR-0033_performance_analytics_expansion.md).

Phases A–C are implemented: extended risk metrics, benchmark-relative analysis,
per-holding return contribution, and deposit impact. Deferred metrics remain
grouped in ADR-0033 by their blocker (risk-free-rate data, convention choice,
book age, or classification data). This file does not maintain a second metric
queue.
